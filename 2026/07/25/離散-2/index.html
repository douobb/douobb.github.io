L2 關係與函數

L2-2 基本關係

定義

  • reflexive (反身性): R 具有反身性⟺∀a∈A, (a,a)∈RR\text{ 具有反身性}\Longleftrightarrow\forall a\in A,\ (a,a)\in RR 具有反身性⟺∀a∈A, (a,a)∈R

  • irreflexive (非反身性): R 具有非反身性⟺∀a∈A, (a,a)∉RR\text{ 具有非反身性}\Longleftrightarrow\forall a\in A,\ (a,a)\notin RR 具有非反身性⟺∀a∈A, (a,a)∈/​R

Note

若 ∣A∣=n|A|=n∣A∣=n:

  • AAA 上的 binary relation 個數: 2n22^{n^2}2n2
  • AAA 上的 reflexive relation 個數: 2n2−n2^{n^2-n}2n2−n
  • AAA 上的 irreflexive relation 個數: 2n2−n2^{n^2-n}2n2−n
定義

  • symmetric (對稱性): ∀a,b∈A,aRb⇒bRa\forall a,b\in A, aRb\Rightarrow bRa∀a,b∈A,aRb⇒bRa

  • asymmetric (非對稱性): ∀a,b∈A,aRb⇒¬(bRa)\forall a,b\in A, aRb\Rightarrow\neg(bRa)∀a,b∈A,aRb⇒¬(bRa)

    • asymmetric relation 一定具有 irreflexive

  • antisymmetric (反對稱性): ∀a,b∈A,(aRb∧bRa)⇒a=b\forall a,b\in A, (aRb\land bRa)\Rightarrow a=b∀a,b∈A,(aRb∧bRa)⇒a=b

Note

若 ∣A∣=n|A|=n∣A∣=n:

  • AAA 上的 symmetric relation 個數: 2n(n+1)22^{\frac{n(n+1)}{2}}22n(n+1)​
  • AAA 上的 asymmetric relation 個數: 3(n2)3^{\binom{n}{2}}3(2n​)
    • 對角線固定為 0
  • AAA 上的 antisymmetric relation 個數: 2n⋅3(n2)2^n\cdot3^{\binom{n}{2}}2n⋅3(2n​)
    • 對角線可 0/1
定義
  • transitive (遞移性): ∀a,b,c∈A, (aRb∧bRc)⇒aRc\forall a,b,c\in A,\ (aRb\land bRc)\Rightarrow aRc∀a,b,c∈A, (aRb∧bRc)⇒aRc
    • ≤\leq≤、整除具有遞移性；≠\neq​=、朋友關係不具有遞移性

L2-3 等價關係

定義

equivalence relation (等價關係): R⊆A×AR\subseteq A\times AR⊆A×A 同時具有 reflexive、symmetric、transitive

定義

若 RRR 為 AAA 上的 equivalence relation，a∈Aa\in Aa∈A:

[a]={x∈A∣xRa}[a]=\{x\in A\mid xRa\}[a]={x∈A∣xRa} 稱為 aaa 的 equivalence class (等價類)

定義

若 A1,…,Ak⊆AA_1,\ldots,A_k\subseteq AA1​,…,Ak​⊆A 滿足:

  • Ai≠∅A_i\neq\varnothingAi​​=∅
  • A1∪⋯∪Ak=AA_1\cup\cdots\cup A_k=AA1​∪⋯∪Ak​=A (cover)
  • Ai∩Aj=∅, ∀i≠jA_i\cap A_j=\varnothing,\ \forall i\neq jAi​∩Aj​=∅, ∀i​=j (disjoint)

則稱 {A1,…,Ak}\{A_1,\ldots,A_k\}{A1​,…,Ak​} 為 AAA 的 partition (分割)。

定理

若 RRR 為 AAA 上的 equivalence relation，則 P={[a]∣a∈A}P=\{[a]\mid a\in A\}P={[a]∣a∈A} 形成 AAA 的 partition。

  • 相異等價類會形成分割
  • 等價關係與分割一一對應

L2-7 計數問題

定義

若存在 bijection (1-1, onto) f:A→Bf:A\to Bf:A→B，則稱 AAA 與 BBB 具有相同的 cardinality (基數)，記作 A∼BA\sim BA∼B。

定義

若 A=∅A=\varnothingA=∅，或存在 n∈Z+n\in\mathbb{Z}^+n∈Z+ 使得 A∼{1,2,…,n}A\sim\{1,2,\ldots,n\}A∼{1,2,…,n}，則稱 AAA 為 finite set (有限集)；否則稱為 infinite set。

定義

若 AAA 為 finite set，或 A∼Z+A\sim\mathbb{Z}^+A∼Z+，則稱 AAA 為 countable set (可數集)。

Note
  • 若 A,BA,BA,B 為 countable set，則 A×BA\times BA×B 也是 countable set
