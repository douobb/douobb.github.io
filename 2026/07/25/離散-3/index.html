L3-2~3 排列 & 組合

定義

  • nnn 件相異物不允許重複取 rrr 件排列: PrnP_{r}^{n}Prn​

  • nnn 件相異物允許重複取 rrr 件排列: nrn^rnr

  • nnn 件相異物不允許重複取 rrr 件組合: (nr)\binom{n}{r}(rn​)

  • nnn 件相異物允許重複取 rrr 件組合: (n+r−1r)\binom{n+r-1}{r}(rn+r−1​)，且等價於

    • rrr 個相同球放至 nnn 個相異箱子，允許空箱之方法數
    • x1+x2+⋯+xn=rx_1 + x_2 + \cdots + x_n = rx1​+x2​+⋯+xn​=r 之非負整數解個數

  • x1+x2+⋯+xn=rx_1 + x_2 + \cdots + x_n = rx1​+x2​+⋯+xn​=r 之正整數解個數: (r−1n−1)\binom{r-1}{n-1}(n−1r−1​)

Note

∣A∣=m,∣B∣=n|A|=m, |B|=n∣A∣=m,∣B∣=n

  • AAA 至 BBB 之 function 個數: nmn^mnm
  • AAA 至 BBB 之 1-1 function 個數: PmnP_{m}^{n}Pmn​

L3-4 排容原理

定理

Principle of Inclusion and Exclusion (排容原理):

N(aˉ1aˉ2⋯aˉn)=∣U∣−∑i=1nN(ai)+∑1≤i<j≤nN(aiaj)−∑1≤i<j<k≤nN(aiajak)+⋯+(−1)nN(a1a2⋯an)=S0−S1+S2−⋯+(−1)nSn \begin{aligned} N(\bar a_1\bar a_2\cdots\bar a_n) &=|U|-\sum_{i=1}^{n}N(a_i)+\sum_{1\leq i<j\leq n}N(a_i a_j)-\sum_{1\leq i<j<k\leq n}N(a_i a_j a_k)+\cdots+(-1)^nN(a_1a_2\cdots a_n)\\ &=S_0-S_1+S_2-\cdots+(-1)^nS_n \end{aligned} N(aˉ1​aˉ2​⋯aˉn​)​=∣U∣−i=1∑n​N(ai​)+1≤i<j≤n∑​N(ai​aj​)−1≤i<j<k≤n∑​N(ai​aj​ak​)+⋯+(−1)nN(a1​a2​⋯an​)=S0​−S1​+S2​−⋯+(−1)nSn​​

其中 SrS_rSr​ 為所有 rrr 個性質同時成立之數量總和，S0=∣U∣S_0=|U|S0​=∣U∣。

定義

若 ∣A∣=m,∣B∣=n,m≥n|A|=m, |B|=n, m\geq n∣A∣=m,∣B∣=n,m≥n，則 AAA 至 BBB 的 onto function 個數為:

onto⁡(m,n)=∑i=0n(−1)i(ni)(n−i)m\operatorname{onto}(m,n)=\sum_{i=0}^{n}(-1)^i\binom{n}{i}(n-i)^m onto(m,n)=i=0∑n​(−1)i(in​)(n−i)m

  • mmm 個相異物放至 nnn 個相異箱子，不允許空箱之方法數
證明

令 UUU 為所有 A→BA\to BA→B 的 function，故 ∣U∣=nm|U|=n^m∣U∣=nm；令 aia_iai​ 表示 BBB 中第 iii 個元素沒有原像。

onto function 須讓所有 aia_iai​ 都不成立，因此套用排容原理。任選 iii 個元素沒有原像時，每個 AAA 中元素只剩 n−in-in−i 個像可選，共有 (n−i)m(n-i)^m(n−i)m 種；選這 iii 個元素有 (ni)\binom ni(in​) 種。

故 onto⁡(m,n)=∑i=0n(−1)i(ni)(n−i)m\operatorname{onto}(m,n)=\displaystyle\sum_{i=0}^{n}(-1)^i\binom ni(n-i)^monto(m,n)=i=0∑n​(−1)i(in​)(n−i)m。

定義

mmm 個相異物分成 nnn 個相同箱子，不允許空箱之方法數，稱為 Stirling number of the second kind: S(m,n)=onto⁡(m,n)n!S(m,n)=\frac{\operatorname{onto}(m,n)}{n!}S(m,n)=n!onto(m,n)​

Note

mmm 個相異物分成 nnn 個相同箱子，允許空箱之方法數: S(m,n)+S(m,n−1)+⋯+S(m,1)S(m,n)+S(m,n-1)+\cdots+S(m,1)S(m,n)+S(m,n−1)+⋯+S(m,1)

定理

S(m+1,n)=S(m,n−1)+nS(m,n)S(m+1,n)=S(m,n-1)+nS(m,n)S(m+1,n)=S(m,n−1)+nS(m,n)

證明

固定其中一物 AAA，分成兩種情況:

  • AAA 單獨一箱: 其餘 mmm 個相異物分成 n−1n-1n−1 箱，共 S(m,n−1)S(m,n-1)S(m,n−1) 種
  • AAA 不單獨一箱: 先將其餘 mmm 個相異物分成 nnn 箱，再選一箱放入 AAA，共 nS(m,n)nS(m,n)nS(m,n) 種

L3-5 亂序及禁位問題

定理

derangement (亂序): {1,2,…,n}\{1,2,\ldots,n\}{1,2,…,n} 的排列中，每個元素皆不在原本位置之排列數為:

Dn=n!∑i=0n(−1)ii!D_n=n!\sum_{i=0}^{n}\frac{(-1)^i}{i!}Dn​=n!∑i=0n​i!(−1)i​

證明

令 UUU 為所有排列，故 ∣U∣=n!|U|=n!∣U∣=n!；令 aia_iai​ 表示元素 iii 位於自然位置。

指定 iii 個元素位於自然位置時，其餘元素可任意排列，有 (n−i)!(n-i)!(n−i)! 種，選定這 iii 個元素有 (ni)\binom ni(in​) 種。由排容原理:
