L6 圖論

L6-1 種類與術語

定義
  • simple graph: 任意兩個相異頂點之間至多有一條邊，且不含自迴圈的圖
    • 否則可稱為 multigraph
  • Path: 不含重複點
    • close: Cycle
  • Trail: 不含重複邊
    • close: Circuit
定義
  • Subgraph
    • Induced subgraph: E′=E∩(V′×V′)E'=E\cap(V'\times V')E′=E∩(V′×V′) (取點上所有屬於原圖的邊)
  • Spanning subgraph: 若 V′=VV'=VV′=V (取原圖所有點)
  • Connected component: 極大 Induced subgraph (盡可能大)
    • GGG 的 component 個數記為 κ(G)\kappa(G)κ(G)。
定義
  • Cut point/articulation point: 對連通圖 GGG，移除頂點 vvv 與其相鄰邊後，G−vG-vG−v 不連通
  • Cut set: 對連通圖 GGG，移除最小邊集合 X⊆EX\subseteq EX⊆E 後圖變得不連通
  • Bridge: 單一邊 eee 本身構成 cut set
  • Biconnected graph: 不含 cut point 的連通圖稱為 biconnected graph。
  • Biconnected component: 圖 GGG 的極大 biconnected induced subgraph 稱為一個 biconnected component。
定義
  • Complete graph: 設 ∣V∣=n|V|=n∣V∣=n。若任意兩個相異頂點皆有一條邊相連，則 GGG 稱為 complete graph，記為 KnK_nKn​。
    • KnK_nKn​ 的邊數為 (n2)\displaystyle\binom{n}{2}(2n​)。
  • Complete tournament: 若有向圖中任意兩個相異頂點之間恰有一條有向邊，則稱為 complete tournament，記為 Kn∗K_n^*Kn∗​。
    • nnn 個帶標號頂點可形成的 complete tournament 數量為 2(n2)\displaystyle 2^{\binom{n}{2}}2(2n​)。
  • Complement graph: 對簡單圖 G=(V,E)G=(V,E)G=(V,E)，其補圖記為 G‾=(V,E‾)\overline{G}=(V,\overline{E})G=(V,E)，且對任意相異頂點 u,v∈Vu,v\in Vu,v∈V，{u,v}∈E‾⟺{u,v}∉E\{u,v\}\in\overline{E}\Longleftrightarrow\{u,v\}\notin E{u,v}∈E⟺{u,v}∈/​E

若 ∣E∣≥(n−12)+1|E|\ge\binom{n-1}{2}+1∣E∣≥(2n−1​)+1，則 GGG 必為連通圖。

  • 1 個點 + Kn−1K_{n-1}Kn−1​ + 1 條邊 (鴿籠原理最差情況)

  • Clique: 圖 GGG 的 complete subgraph 稱為 clique
    • maximal clique
  • Independent set: 任兩個頂點皆無邊相連的頂點集合
    • maximal independent set: set 可以只有一個點
  • Dominating set: 頂點集合 S⊆VS\subseteq VS⊆V 使每個不在 SSS 的頂點皆與 SSS 中至少一個頂點相鄰
    • 頂點 Dominating 頂點

    • 頂點 Cover 邊
    • minimal vertex cover

L6-2 表示法與同構

定義
  • Degree: 對 v∈Vv\in Vv∈V，deg⁡(v)\deg(v)deg(v) 表示與 vvv 相接的邊數。
  • Indegree 與 outdegree: 在有向圖中，id⁡(v)\operatorname{id}(v)id(v) 表示指向 vvv 的邊數，od⁡(v)\operatorname{od}(v)od(v) 表示由 vvv 指出的邊數。
  • k-regular graph: 所有頂點 v∈Vv\in Vv∈V 皆滿足 deg⁡(v)=k\deg(v)=kdeg(v)=k。
定義

設 G1=(V1,E1)G_1=(V_1,E_1)G1​=(V1​,E1​)、G2=(V2,E2)G_2=(V_2,E_2)G2​=(V2​,E2​)。若存在雙射 f:V1→V2f:V_1\to V_2f:V1​→V2​

Note

同構圖具有下列不變性:

  • 頂點數與邊數
  • 由大到小排列的 degree sequence
  • 連通分量數與各分量的結構
  • cycle 等子圖結構
  • 對應頂點的鄰接關係與 degree
  • 補圖的同構關係

若任一不變性不同，兩圖必不同構；反之，不變性相同不一定保證同構。

  • 證明同構: 給出函數 fff (點的對應關係)
  • 證明不同構: 利用以上不變性
    • 某點周圍之點的 degrees
    • 某 cycle 經過的點的 degrees
    • 補圖不同構 (如果原圖邊數很多)

L6-4 Euler circuit 與 Hamilton cycle

定義
  • Euler circuit: 恰好經過圖中每一條邊一次的 circuit。
  • Hamilton cycle: 恰好經過圖中每一個頂點一次的 cycle。
定理

設 G=(V,E)G=(V,E)G=(V,E) 為 simple graph 或 multigraph。
GGG 具有 Euler circuit ⟺G\Longleftrightarrow G⟺G 為連通圖且 deg⁡(v)\deg(v)deg(v) 為偶數 ∀v∈V\forall v\in V∀v∈V

若 G=(V,E)G=(V,E)G=(V,E) 為有向圖，則
GGG 具有 Euler circuit ⟺G\Longleftrightarrow G⟺G 為 strongly connected 且 id⁡(v)=od⁡(v),∀v∈V\operatorname{id}(v)=\operatorname{od}(v), \forall v\in Vid(v)=od(v),∀v∈V

定理

每個 complete tournament Kn∗K_n^*Kn∗​ 皆具有 Hamiltonian path (HP)。

Note

  • KnK_nKn​ 具有 Euler circuit ⟺n\Longleftrightarrow n⟺n 為奇數。

  • KnK_nKn​ 具有 Hamilton cycle (HC)。

  • KnK_nKn​ 中相異 HC 的數量為 (n−1)!2\frac{(n-1)!}{2}2(n−1)!​

Note
  • 判斷圖是否具有 HC: 嘗試畫出一條經過每個頂點一次的 cycle。
  • 判斷圖不具有 HC: 反設存在 HC。由於 HC 通過每個頂點時恰使用兩條相鄰邊，可利用此條件導出矛盾。
