Hypothesis Testing

Hypothesis Testing Framework

Hypothesis testing 的目的，是利用 sample data 判斷對 population parameter 的假設是否有足夠證據反對。

Null Hypothesis 與 Alternative Hypothesis

  • H0H_0H0​: Null hypothesis (虛無假說)，通常代表既有狀態、沒有效果或 parameter 等於指定值，例如 H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​。
  • HaH_aHa​: Alternative hypothesis (對立假說)，通常代表研究者想支持的主張，例如 Ha:μ>μ0H_a:\mu>\mu_0Ha​:μ>μ0​、Ha:μ<μ0H_a:\mu<\mu_0Ha​:μ<μ0​、Ha:μ≠μ0H_a:\mu\neq\mu_0Ha​:μ​=μ0​。

Type I Error 與 Type II Error

真實情況 Fail to reject H0H_0H0​ Reject H0H_0H0​
H0H_0H0​ true 正確 Type I Error
H0H_0H0​ false Type II Error 正確

α\alphaα 稱為 level of significance (顯著水準)，常用 α=0.05\alpha=0.05α=0.05。

  • Type I error: α=P(Reject H0∣H0 is true)\alpha=P(\text{Reject }H_0\mid H_0\text{ is true})α=P(Reject H0​∣H0​ is true)
  • Type II error: β=P(Fail to reject H0∣H0 is false)\beta=P(\text{Fail to reject }H_0\mid H_0\text{ is false})β=P(Fail to reject H0​∣H0​ is false)

三種 Hypothesis Testing

  • Case 1: Right-tailed
    • H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​
    • Ha:μ>μ0H_a:\mu>\mu_0Ha​:μ>μ0​
    • 大的 sample mean 對 H0H_0H0​ 不利，rejection region 在右尾。
  • Case 2: Left-tailed
    • H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​
    • Ha:μ<μ0H_a:\mu<\mu_0Ha​:μ<μ0​
    • 小的 sample mean 對 H0H_0H0​ 不利，rejection region 在左尾。
  • Case 3: Two-tailed
    • H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​
    • Ha:μ≠μ0H_a:\mu\neq\mu_0Ha​:μ​=μ0​
    • sample mean 太大或太小都對 H0H_0H0​ 不利，左右兩尾都是 rejection region。

標準答題流程:

  1. 寫 H0 與 Ha
  2. 指定 α
  3. 由 Ha 決定 one-tail / two-tail
  4. 計算 test statistic
  5. 用 rejection rule 或 p-value 判斷
  6. 寫 Reject H0 或 Fail to reject H0
  7. 用題目語意解釋結果

應寫 Fail to reject H0H_0H0​，不要直接寫成 Accept H0H_0H0​，因為證據不足以拒絕不代表已證明 H0H_0H0​ 正確。

三種 Decision Methods

  • Rejection rule: 看 test statistic 是否落入 rejection region。
  • p-value: 計算 data 往「更有利於 HaH_aHa​」方向的 tail probability，再與 α\alphaα 比較。
  • Confidence interval: two-sided test 可看 hypothesized value 是否落在 CI 中。

Z Test for μ\muμ when σ\sigmaσ Known

若 Xi∼iidN(μ,σ2)X_i\overset{iid}{\sim}N(\mu,\sigma^2)Xi​∼iidN(μ,σ2)，且 σ\sigmaσ 已知，在 H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​ 下: Xˉ∼N(μ0,σ2n)\bar X\sim N\left(\mu_0,\frac{\sigma^2}{n}\right)Xˉ∼N(μ0​,nσ2​)

Test statistic: zobs=xˉobs−μ0σ/nz_{obs}=\frac{\bar x_{obs}-\mu_0}{\sigma/\sqrt n}zobs​=σ/n​xˉobs​−μ0​​

Z Test Rejection Rules:

  • Right-tailed
    • Ha:μ>μ0H_a:\mu>\mu_0Ha​:μ>μ0​，Reject H0H_0H0​ if: zobs>zαz_{obs}>z_\alphazobs​>zα​
    • 等價地: xˉobs>μ0+zασn\bar x_{obs}>\mu_0+z_\alpha\frac{\sigma}{\sqrt n}xˉobs​>μ0​+zα​n​σ​，其中 P(Z>zα)=αP(Z>z_\alpha)=\alphaP(Z>zα​)=α。
  • Left-tailed
    • Ha:μ<μ0H_a:\mu<\mu_0Ha​:μ<μ0​，Reject H0H_0H0​ if: zobs<−zαz_{obs}<-z_\alphazobs​<−zα​
    • 等價地: xˉobs<μ0−zασn\bar x_{obs}<\mu_0-z_\alpha\frac{\sigma}{\sqrt n}xˉobs​<μ0​−zα​n​σ​
  • Two-tailed
    • Ha:μ≠μ0H_a:\mu\neq\mu_0Ha​:μ​=μ0​
    • Reject H0H_0H0​ if: ∣zobs∣>zα/2|z_{obs}|>z_{\alpha/2}∣zobs​∣>zα/2​
    • 也就是: xˉobs>μ0+zα/2σn\bar x_{obs}>\mu_0+z_{\alpha/2}\frac{\sigma}{\sqrt n}xˉobs​>μ0​+zα/2​n​σ​ 或 xˉobs<μ0−zα/2σn\bar x_{obs}<\mu_0-z_{\alpha/2}\frac{\sigma}{\sqrt n}xˉobs​<μ0​−zα/2​n​σ​
    • 有左右兩個 rejection regions，所以每邊的 tail probability 是 α/2\alpha/2α/2。

同樣 α\alphaα 時，two-sided test 的 rejection 標準更嚴格

p-value

在 H0H_0H0​ 成立的前提下，從目前 observed data 往「更有利於 HaH_aHa​」方向的 tail probability。

判斷規則:

  • p-value < α → Reject H0
  • p-value > α → Fail to reject H0

p-value 越小，代表 observed data 在 H0H_0H0​ 下越不尋常，因此反對 H0H_0H0​ 的 evidence 越強。

p-value 的三種形式

  • Right-tailed
    • Ha:μ>μ0H_a:\mu>\mu_0Ha​:μ>μ0​
    • p-value=P(Z>zobs)p\text{-value}=P(Z>z_{obs})p-value=P(Z>zobs​)
  • Left-tailed
    • Ha:μ<μ0H_a:\mu<\mu_0Ha​:μ<μ0​
    • p-value=P(Z<zobs)p\text{-value}=P(Z<z_{obs})p-value=P(Z<zobs​)
  • Two-tailed
    • Ha:μ≠μ0H_a:\mu\neq\mu_0Ha​:μ​=μ0​
    • p-value=2P(Z>∣zobs∣)p\text{-value}=2P(Z>|z_{obs}|)p-value=2P(Z>∣zobs​∣)
    • 乘 2 因為左右兩個方向都對 H0H_0H0​ 不利。

Rejection Rule 與 p-value 的關係

Test statistic 落入 rejection region ⇔ p-value < α ⇔ Reject H0

反之: Test statistic 不在 rejection region ⇔ p-value > α ⇔ Fail to reject H0

p-value 的優點是能顯示 evidence strength，不只是得到二元的 reject / fail to reject。

Confidence Interval 用於 Two-sided Test

對 H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​ vs. Ha:μ≠μ0H_a:\mu\neq\mu_0Ha​:μ​=μ0​，若 σ\sigmaσ known，(1−α)100%(1-\alpha)100\%(1−α)100% CI 為: [xˉobs−zα/2σn, xˉobs+zα/2σn]\left[\bar x_{obs}-z_{\alpha/2}\frac{\sigma}{\sqrt n},\ \bar x_{obs}+z_{\alpha/2}\frac{\sigma}{\sqrt n}\right][xˉobs​−zα/2​n​σ​, xˉobs​+zα/2​n​σ​]

判斷:

  • μ0 不在 CI 中 → Reject H0
  • μ0 在 CI 中 → Fail to reject H0

Confidence interval 的 midpoint 是 xˉobs\bar x_{obs}xˉobs​，不是 μ0\mu_0μ0​。

Hypothesis Testing for Population Proportion ppp

要檢定 H0:p=p0H_0:p=p_0H0​:p=p0​
Sample proportion: p^=Xn\hat p=\frac{X}{n}p^​=nX​

可以使用:

  • Exact Binomial test
  • Large-sample Z test

Exact Binomial Test

若 sample size 不大，在 H0:p=p0H_0:p=p_0H0​:p=p0​ 下 X∼Binomial(n,p0)X\sim Binomial(n,p_0)X∼Binomial(n,p0​)

例如左尾檢定 Ha:p<p0H_a:p<p_0Ha​:p<p0​: p-value=P(X≤xobs∣p=p0)p\text{-value}=P(X\le x_{obs}\mid p=p_0)p-value=P(X≤xobs​∣p=p0​)

直接使用 Binomial probabilities 加總，得到 exact result。

Large-sample Z Test for ppp

當 nnn 足夠大時，可以使用 Normal approximation。

Test statistic: zobs=p^−p0p0(1−p0)/nz_{obs}=\frac{\hat p-p_0}{\sqrt{p_0(1-p_0)/n}}zobs​=p0​(1−p0​)/n​p^​−p0​​

Hypothesis testing 的 denominator 使用 p0p_0p0​，不是 p^\hat pp^​。
因為我們是在 H0:p=p0H_0:p=p_0H0​:p=p0​ 成立的前提下建立 sampling distribution。

  • Hypothesis Testing
    • H0:p=p0H_0:p=p_0H0​:p=p0​
    • Standard error 使用: p0(1−p0)n\sqrt{\frac{p_0(1-p_0)}{n}}np0​(1−p0​)​​
  • Interval Estimation
    • 真實 ppp 未知，所以使用 sample estimate p^\hat pp^​: p^(1−p^)n\sqrt{\frac{\hat p(1-\hat p)}{n}}np^​(1−p^​)​​
    • Confidence interval: p^±zα/2p^(1−p^)n\hat p\pm z_{\alpha/2}\sqrt{\frac{\hat p(1-\hat p)}{n}}p^​±zα/2​np^​(1−p^​)​​

T Test when σ\sigmaσ Unknown

若 σ\sigmaσ unknown，使用 sample standard deviation SSS 估計。

假設 Xi∼iidN(μ,σ2)X_i\overset{iid}{\sim}N(\mu,\sigma^2)Xi​∼iidN(μ,σ2)

則 Xˉ−μS/n∼Tn−1\frac{\bar X-\mu}{S/\sqrt n}\sim T_{n-1}S/n​Xˉ−μ​∼Tn−1​

Test statistic: tobs=xˉobs−μ0s/nt_{obs}=\frac{\bar x_{obs}-\mu_0}{s/\sqrt n}tobs​=s/n​xˉobs​−μ0​​

Degree of freedom: df=n−1df=n-1df=n−1

T Test Rejection Rules

  • Right-tailed
    • Ha:μ>μ0H_a:\mu>\mu_0Ha​:μ>μ0​
    • Reject H0H_0H0​ if: tobs>tn−1,αt_{obs}>t_{n-1,\alpha}tobs​>tn−1,α​
    • p-value: p-value=P(Tn−1>tobs)p\text{-value}=P(T_{n-1}>t_{obs})p-value=P(Tn−1​>tobs​)
  • Left-tailed
    • Ha:μ<μ0H_a:\mu<\mu_0Ha​:μ<μ0​
    • Reject H0H_0H0​ if: tobs<−tn−1,αt_{obs}<-t_{n-1,\alpha}tobs​<−tn−1,α​
    • p-value: p-value=P(Tn−1<tobs)p\text{-value}=P(T_{n-1}<t_{obs})p-value=P(Tn−1​<tobs​)
  • Two-tailed
    • Ha:μ≠μ0H_a:\mu\neq\mu_0Ha​:μ​=μ0​
    • Reject H0H_0H0​ if: ∣tobs∣>tn−1,α/2|t_{obs}|>t_{n-1,\alpha/2}∣tobs​∣>tn−1,α/2​
    • p-value: p-value=2P(Tn−1>∣tobs∣)p\text{-value}=2P(T_{n-1}>|t_{obs}|)p-value=2P(Tn−1​>∣tobs​∣)

T Test 與 Confidence Interval

Two-sided T test 對應的 (1−α)100%(1-\alpha)100\%(1−α)100% T confidence interval: xˉobs±tn−1,α/2sn\bar x_{obs}\pm t_{n-1,\alpha/2}\frac{s}{\sqrt n}xˉobs​±tn−1,α/2​n​s​

  • μ0 不在 CI 中 → Reject H0
  • μ0 在 CI 中 → Fail to reject H0

Z Test vs. T Test

Z Test T Test
Population SD σ\sigmaσ known σ\sigmaσ unknown
Standard error σ/n\sigma/\sqrt nσ/n​ s/ns/\sqrt ns/n​
Distribution N(0,1)N(0,1)N(0,1) Tn−1T_{n-1}Tn−1​
Critical value zzz ttt
Tail 較輕 較重

若剛好 s=σs=\sigmas=σ，則同一 confidence level 下: tn−1,α/2≥zα/2t_{n-1,\alpha/2}\ge z_{\alpha/2}tn−1,α/2​≥zα/2​

所以 T interval 通常比 Z interval 寬，T test 也較不容易 reject H0H_0H0​。

原因是 σ\sigmaσ 未知，需要額外估計，因此 uncertainty 增加。
