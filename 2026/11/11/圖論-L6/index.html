Planar Graph 與 Plane Graph

若一個圖存在一種畫法，使任意兩條邊都不交叉，則稱為 planar graph (可平面圖)。
plane graph (平面圖) 則是 planar graph 的某一個特定平面嵌入。

所以:

  • planar graph: 問「是否存在不交叉畫法」
  • plane graph: 已經固定某一個不交叉畫法

重要例子:

  • K4K_4K4​ 是 planar
  • K5K_5K5​ 是 nonplanar
  • K3,3K_{3,3}K3,3​ 是 nonplanar

plane graph 會把平面分成數個連通區域，每個區域稱為 face。

  • exterior face: 唯一無界的面
  • interior face: 其餘有界的面

內部面與外部面本質上沒有差別，可以透過球面投影互換。

某個 face 的 boundary 是與該面相交的頂點與邊所形成的子圖。
face FFF 的長度 ℓ(F)\ell(F)ℓ(F) 是其 boundary walk 中經過邊的次數。

注意:

  • cycle 上的邊通常屬於兩個面
  • bridge 只屬於一個面
  • 但 bridge 在同一個面的 boundary walk 中會被計算兩次

plane graph 中所有 face 的長度總和為: ∑Fℓ(F)=2e\sum_F \ell(F)=2e∑F​ℓ(F)=2e
原因是每條邊在所有 face boundary 中總共被計算兩次。

Euler’s Formula

若 GGG 是 connected plane graph，具有 nnn 個頂點、eee 條邊、fff 個面，則: n−e+f=2n-e+f=2n−e+f=2

證明在講義 P19-21

簡單平面圖的邊數上界

若簡單 planar graph 有 n≥3n\ge3n≥3 個頂點，則: e≤3n−6e\le3n-6e≤3n−6

因為每個 face 至少被 3 條邊圍成，所以: 3f≤2e3f\le2e3f≤2e

再配合 Euler formula 即可得到結果。

證明在講義 P22

若 GGG 是簡單 planar bipartite graph，則: e≤2n−4e\le2n-4e≤2n−4

bipartite graph 沒有 odd cycle，因此每個 face 至少長度 4: 4f≤2e4f\le2e4f≤2e

更一般地，若每個 face 長度至少為 ℓ\ellℓ，則: e≤ℓℓ−2(n−2)e\le\frac{\ell}{\ell-2}(n-2)e≤ℓ−2ℓ​(n−2)

子圖與 Planarity

若 GGG 是 planar，則 GGG 的所有 subgraph 也都是 planar。

若 GGG 含有某個 nonplanar subgraph，則 GGG 一定 nonplanar。

Dual Graph 對偶圖

對 plane graph GGG，dual graph G∗G^*G∗ 的建立方式:

  • GGG 的每個 face 對應 G∗G^*G∗ 的一個 vertex
  • GGG 的每條 edge 對應 G∗G^*G∗ 的一條 edge
  • 若一條邊兩側是 face X,YX,YX,Y，則 dual 中連接對應 X,YX,YX,Y 的頂點

因此:

  • face ↔\leftrightarrow↔ vertex
  • edge ↔\leftrightarrow↔ edge

而且: e(G)=e(G∗)e(G)=e(G^*)e(G)=e(G∗)

dual graph 可能有 loop 與 parallel edges。

若 GGG connected，則: (G∗)∗≅G(G^*)^*\cong G(G∗)∗≅G

同一個 planar graph 因 embedding 不同，可能得到不同構的 dual。

Maximal Planar Graph

若 planar graph GGG 已經不能再對任意兩個不相鄰頂點加邊並保持 planar，則稱為 maximal planar。

重要特性: maximal planar graph 的每個 face 都是 triangle。
此時: e=3n−6e=3n-6e=3n−6

對 maximal planar bipartite graph，每個 face 的長度正好為 4。
此時: e=2n−4e=2n-4e=2n−4

由 e≤3n−6e\le3n-6e≤3n−6，以及 ∑v∈V(G)deg⁡(v)=2e\sum_{v\in V(G)}\deg(v)=2e∑v∈V(G)​deg(v)=2e

可以推得任意簡單 planar graph 一定存在 degree 至多 5 的頂點: δ(G)≤5\delta(G)\le5δ(G)≤5

Kuratowski Theorem

一個圖 GGG 是 planar 若且唯若它不包含:

  • K5K_5K5​ 的 subdivision
  • K3,3K_{3,3}K3,3​ 的 subdivision

Subdivision: 對一條邊加入新頂點，將原本的一條 edge 替換成 path。

指定面可改成外部面

若 FFF 是圖 GGG 的某個平面嵌入中的一個 face boundary，則存在另一個平面嵌入，使得 FFF 成為 exterior face。

證明想法 (講義 P55):

  1. 先把原本的平面嵌入投影到球面上。
  2. 在球面上，每一個面都只是普通的有界區域，沒有哪一個面天生是「外部面」。
  3. 從想指定為 exterior face 的面 FFF 開孔，再把球面投影回平面。
  4. 此時 FFF 就會成為新的外部面。

Minimal Nonplanar Graph

若一個 nonplanar graph GGG 刪除任何一部分後都變 planar，則稱為 minimal nonplanar graph。

Lemma: 任意 minimal nonplanar graph 都是 2-connected。

證明 (討論兩種不滿足 2-connected 的情況):

  • Case 1: GGG 不連通
  • Case 2: GGG 有 cut vertex vvv

證明在講義 P56-59

2-Vertex Cut Lemma

假設 S={x,y}S=\{x,y\}S={x,y} 是 GGG 的 vertex cut，也就是 G−SG-SG−S 不連通。

若 GGG 是 nonplanar，則在 x,yx,yx,y 之間加入邊 xyxyxy 後，所得圖仍然 nonplanar。

證明在講義 P61-63

最小 Kuratowski 反例必為 3-Connecte

這裡先假設存在一個反例:

  • GGG 是 nonplanar
  • GGG 不含 K5K_5K5​ 或 K3,3K_{3,3}K3,3​ 的 subdivision
  • 在所有這類反例中，GGG 的邊數最少

Lemma: 這樣的 GGG 必須是 3-connected。

Thomassen Lemma

Edge Contraction: 對邊 xyxyxy 做 edge contraction:

  • 移除邊 xyxyxy。
  • 將 x,yx,yx,y 合併成一個頂點。

以 G/xyG/xyG/xy 表示 contraction 後的圖。

Lemma: 若 GGG 是至少 5 個頂點的 3-connected graph，則存在一條邊 xyxyxy，使得 G/xyG/xyG/xy 仍然是 3-connected。

證明在講義 P70-P75

Contraction 不會新產生 Kuratowski Subgraph

Lemma: 若 GGG 不含 Kuratowski subgraph，則 G/xyG/xyG/xy 也不含 Kuratowski subgraph。

證明 (講義 P76-80):
反設 G/xyG/xyG/xy 中存在 Kuratowski subgraph HHH。
令 zzz 是 contraction 後由 x,yx,yx,y 合併得到的頂點。
依 zzz 是否出現在 HHH 中，以及它在 HHH 中的 degree 分情況討論。

Kuratowski Theorem

Kuratowski Theorem: 一個圖是可平面的 若且唯若 它不包含 K5K_5K5​ 和 K3,3K_{3,3}K3,3​ 的細分

Tutte Theorem (更強): 如果 GGG 是一个不含 K5K_5K5​ 和 K3,3K_{3,3}K3,3​ 的細分的3-連通圖，則存在 GGG 的平面凸嵌入，使得任意三個頂點都不在一條直線上。

證明在講義 P82-P86

Five Color Theorem

Five Color Theorem: 任何 planar graph 都是 5-colorable。
也就是 χ(G)≤5\chi(G)\le5χ(G)≤5

證明在講義 P90-P95

face coloring 可以透過 dual graph 轉成 vertex coloring

  • 原圖 face 對應 dual vertex
  • 相鄰 face 對應 dual 中相鄰 vertices
