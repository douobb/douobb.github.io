Power, Paired Test & Two-sample Tests

Power Function (檢定力)

假設檢定中:

  • α=P(Reject H0∣H0 true)\alpha=P(\text{Reject }H_0\mid H_0\text{ true})α=P(Reject H0​∣H0​ true)，為 Type I error rate。
  • β=P(Fail to reject H0∣H0 false)\beta=P(\text{Fail to reject }H_0\mid H_0\text{ false})β=P(Fail to reject H0​∣H0​ false)，為 Type II error rate。

Power 是 H0H_0H0​ 錯誤時，正確拒絕 H0H_0H0​ 的機率。因此 Power=1−βPower=1-\betaPower=1−β
也可以寫成 Power=P(Reject H0∣H0 false)Power=P(\text{Reject }H_0\mid H_0\text{ false})Power=P(Reject H0​∣H0​ false)

計算 power 時必須指定 alternative 下的真實值 μ=μa\mu=\mu_aμ=μa​，因此:

  • Power(μa)=P(Reject H0∣μ=μa)Power(\mu_a)=P(\text{Reject }H_0\mid\mu=\mu_a)Power(μa​)=P(Reject H0​∣μ=μa​)
  • Power 不是單一固定值，而是 μa\mu_aμa​ 的函數。

Power 計算流程

  1. 由 Ha 決定 rejection rule
  2. 指定 alternative 下真正的 μ = μa
  3. 在 μ = μa 的 distribution 下，計算「落入 rejection region」的 probability

Rejection rule 由 H0H_0H0​ 與 α\alphaα 決定，但 power 的 probability 要在 μ=μa\mu=\mu_aμ=μa​ 下計算。

One-sample Z Test 的 Power: Right-tailed

Rejection Rule

  • H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​、Ha:μ>μ0H_a:\mu>\mu_0Ha​:μ>μ0​ 且 σ\sigmaσ known。
  • Reject H0H_0H0​ if: Xˉ>μ0+zασn\bar X>\mu_0+z_\alpha\frac{\sigma}{\sqrt n}Xˉ>μ0​+zα​n​σ​

Power Formula
若真正的 mean 為 μ=μa>μ0\mu=\mu_a>\mu_0μ=μa​>μ0​: Power(μa)=P(Xˉ>μ0+zασn∣μ=μa)Power(\mu_a)=P\left(\bar X>\mu_0+z_\alpha\frac{\sigma}{\sqrt n}\mid\mu=\mu_a\right)Power(μa​)=P(Xˉ>μ0​+zα​n​σ​∣μ=μa​)

以 μa\mu_aμa​ 為中心 standardize: Power(μa)=P(Z>μ0−μaσ/n+zα)Power(\mu_a)=P\left(Z>\frac{\mu_0-\mu_a}{\sigma/\sqrt n}+z_\alpha\right)Power(μa​)=P(Z>σ/n​μ0​−μa​​+zα​)

One-sample Z Test 的 Power: Left-tailed

Rejection Rule

  • H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​、Ha:μ<μ0H_a:\mu<\mu_0Ha​:μ<μ0​
  • Reject H0H_0H0​ if: Xˉ<μ0−zασn\bar X<\mu_0-z_\alpha\frac{\sigma}{\sqrt n}Xˉ<μ0​−zα​n​σ​

Power Formula
若 μ=μa<μ0\mu=\mu_a<\mu_0μ=μa​<μ0​: Power(μa)=P(Xˉ<μ0−zασn∣μ=μa)Power(\mu_a)=P\left(\bar X<\mu_0-z_\alpha\frac{\sigma}{\sqrt n}\mid\mu=\mu_a\right)Power(μa​)=P(Xˉ<μ0​−zα​n​σ​∣μ=μa​)

standardize: Power(μa)=P(Z<μ0−μaσ/n−zα)Power(\mu_a)=P\left(Z<\frac{\mu_0-\mu_a}{\sigma/\sqrt n}-z_\alpha\right)Power(μa​)=P(Z<σ/n​μ0​−μa​​−zα​)

Two-tailed Z Test 的 Power

Rejection Rule

  • H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​、Ha:μ≠μ0H_a:\mu\neq\mu_0Ha​:μ​=μ0​
  • Reject H0H_0H0​ if: Xˉ<μ0−zα/2σn\bar X<\mu_0-z_{\alpha/2}\frac{\sigma}{\sqrt n}Xˉ<μ0​−zα/2​n​σ​ 或 Xˉ>μ0+zα/2σn\bar X>\mu_0+z_{\alpha/2}\frac{\sigma}{\sqrt n}Xˉ>μ0​+zα/2​n​σ​

Two-tailed power 等於左右兩個 rejection regions 的 probability 相加:
Power(μa)=P(Xˉ<μ0−zα/2σn∣μ=μa)+P(Xˉ>μ0+zα/2σn∣μ=μa)Power(\mu_a)=P\left(\bar X<\mu_0-z_{\alpha/2}\frac{\sigma}{\sqrt n}\mid\mu=\mu_a\right)+P\left(\bar X>\mu_0+z_{\alpha/2}\frac{\sigma}{\sqrt n}\mid\mu=\mu_a\right)Power(μa​)=P(Xˉ<μ0​−zα/2​n​σ​∣μ=μa​)+P(Xˉ>μ0​+zα/2​n​σ​∣μ=μa​)

standardize 後:
Power(μa)=P(Z<μ0−μaσ/n−zα/2)+P(Z>μ0−μaσ/n+zα/2)Power(\mu_a)=P\left(Z<\frac{\mu_0-\mu_a}{\sigma/\sqrt n}-z_{\alpha/2}\right)+P\left(Z>\frac{\mu_0-\mu_a}{\sigma/\sqrt n}+z_{\alpha/2}\right)Power(μa​)=P(Z<σ/n​μ0​−μa​​−zα/2​)+P(Z>σ/n​μ0​−μa​​+zα/2​)

Two-tailed power 不能只算其中一尾，即使其中一塊通常遠大於另一塊。

對 two-tailed test，power function 以 μ0\mu_0μ0​ 為中心對稱。

若 ∣μa(1)−μ0∣=∣μa(2)−μ0∣|\mu_a^{(1)}-\mu_0|=|\mu_a^{(2)}-\mu_0|∣μa(1)​−μ0​∣=∣μa(2)​−μ0​∣

則 Power(μa(1))=Power(μa(2))Power(\mu_a^{(1)})=Power(\mu_a^{(2)})Power(μa(1)​)=Power(μa(2)​)

例如 μ0=3\mu_0=3μ0​=3 時，μa=2\mu_a=2μa​=2 與 μa=4\mu_a=4μa​=4 的 power 相同。

影響 Power 的因素

  • Effect Size ∣μa−μ0∣|\mu_a-\mu_0|∣μa​−μ0​∣
    • ∣μa−μ0∣|\mu_a-\mu_0|∣μa​−μ0​∣ 越大: Power↑Power\uparrowPower↑
  • Population Standard Deviation
    • σ\sigmaσ 越小: Power↑Power\uparrowPower↑
  • Sample Size nnn
    • nnn 越大: σn↓\frac{\sigma}{\sqrt n}\downarrown​σ​↓，因此 Power↑Power\uparrowPower↑
  • Significance Level α\alphaα
    • α\alphaα 越大，rejection region 越大，因此 α↑⇒Power↑\alpha\uparrow\Rightarrow Power\uparrowα↑⇒Power↑
    • 但代價是 α↑⇒Type I error↑\alpha\uparrow\Rightarrow Type\ I\ error\uparrowα↑⇒Type I error↑

由目標 Power 求最小 Sample Size

研究設計階段常先指定:

  • α\alphaα
  • 希望偵測的 effect size ∣μa−μ0∣|\mu_a-\mu_0|∣μa​−μ0​∣
  • σ\sigmaσ
  • Target power，例如 0.8 或 0.9

再反推出最小 sample size nnn。

Right-tailed Test 的解題流程

假設 H0:μ=μ0H_0:\mu=\mu_0H0​:μ=μ0​、Ha:μ=μa>μ0H_a:\mu=\mu_a>\mu_0Ha​:μ=μa​>μ0​
要求 Power(μa)≥KPower(\mu_a)\ge KPower(μa​)≥K

先保留 rejection rule: Xˉ>μ0+zασn\bar X>\mu_0+z_\alpha\frac{\sigma}{\sqrt n}Xˉ>μ0​+zα​n​σ​

再在 μ=μa\mu=\mu_aμ=μa​ 下 standardize: P(Z>μ0−μaσ/n+zα)≥KP\left(Z>\frac{\mu_0-\mu_a}{\sigma/\sqrt n}+z_\alpha\right)\ge KP(Z>σ/n​μ0​−μa​​+zα​)≥K

接著由 Z table 找 cutoff，再解 nnn。最後最小 sample size 一律向上取整。

Matched-pairs Testing

原始 paired observations: (Xi,Yi)(X_i,Y_i)(Xi​,Yi​)

定義: Di=Yi−XiD_i=Y_i-X_iDi​=Yi​−Xi​

接著只分析 D1,…,DnD_1,\ldots,D_nD1​,…,Dn​。

Paired two-sample problem 會轉換成 one-sample problem。

Paired t Test Statistic

Dˉ=1n∑i=1nDi\bar D=\frac{1}{n}\sum_{i=1}^{n}D_iDˉ=n1​∑i=1n​Di​

SD2=∑i=1n(Di−Dˉ)2n−1S_D^2=\frac{\sum_{i=1}^{n}(D_i-\bar D)^2}{n-1}SD2​=n−1∑i=1n​(Di​−Dˉ)2​

若 Di∼N(μD,σD2)D_i\sim N(\mu_D,\sigma_D^2)Di​∼N(μD​,σD2​)

檢定: H0:μD=0H_0:\mu_D=0H0​:μD​=0

則 tobs=DˉSD/nt_{obs}=\frac{\bar D}{S_D/\sqrt n}tobs​=SD​/n​Dˉ​ 且 T∼tn−1T\sim t_{n-1}T∼tn−1​

三種 alternatives 與 one-sample t test 相同。

Independent Two-sample Comparison

使用條件: 兩個 samples independent: X1i⊥X2jX_{1i}\perp X_{2j}X1i​⊥X2j​

目標是比較 μ1−μ2\mu_1-\mu_2μ1​−μ2​

通常 H0:μ1−μ2=0H_0:\mu_1-\mu_2=0H0​:μ1​−μ2​=0

三種 Alternatives:

  • Ha:μ1−μ2>0H_a:\mu_1-\mu_2>0Ha​:μ1​−μ2​>0
  • Ha:μ1−μ2<0H_a:\mu_1-\mu_2<0Ha​:μ1​−μ2​<0
  • Ha:μ1−μ2≠0H_a:\mu_1-\mu_2\neq0Ha​:μ1​−μ2​​=0

Distribution of Xˉ1−Xˉ2\bar X_1-\bar X_2Xˉ1​−Xˉ2​

Point Estimator

使用 Xˉ1−Xˉ2\bar X_1-\bar X_2Xˉ1​−Xˉ2​ 估計 μ1−μ2\mu_1-\mu_2μ1​−μ2​

且 E(Xˉ1−Xˉ2)=μ1−μ2E(\bar X_1-\bar X_2)=\mu_1-\mu_2E(Xˉ1​−Xˉ2​)=μ1​−μ2​

Variance 與 Standard Error

因兩組 samples independent: Cov(Xˉ1,Xˉ2)=0Cov(\bar X_1,\bar X_2)=0Cov(Xˉ1​,Xˉ2​)=0

所以 Var(Xˉ1−Xˉ2)=σ12n1+σ22n2Var(\bar X_1-\bar X_2)=\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}Var(Xˉ1​−Xˉ2​)=n1​σ12​​+n2​σ22​​

SE(Xˉ1−Xˉ2)=σ12n1+σ22n2SE(\bar X_1-\bar X_2)=\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}SE(Xˉ1​−Xˉ2​)=n1​σ12​​+n2​σ22​​​

若兩 populations 都為 Normal: Xˉ1−Xˉ2∼N(μ1−μ2,σ12n1+σ22n2)\bar X_1-\bar X_2\sim N\left(\mu_1-\mu_2,\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}\right)Xˉ1​−Xˉ2​∼N(μ1​−μ2​,n1​σ12​​+n2​σ22​​)

Two-sample Z Test: σ1,σ2\sigma_1,\sigma_2σ1​,σ2​ Known

Test Statistic

在 H0:μ1−μ2=0H_0:\mu_1-\mu_2=0H0​:μ1​−μ2​=0 下: zobs=(xˉ1−xˉ2)−0σ12/n1+σ22/n2z_{obs}=\frac{(\bar x_1-\bar x_2)-0}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}zobs​=σ12​/n1​+σ22​/n2​​(xˉ1​−xˉ2​)−0​

Right-tailed Test

若 Ha:μ1−μ2>0H_a:\mu_1-\mu_2>0Ha​:μ1​−μ2​>0

Reject H0H_0H0​ if: zobs>zαz_{obs}>z_\alphazobs​>zα​

p-value: p-value=P(Z>zobs)p\text{-value}=P(Z>z_{obs})p-value=P(Z>zobs​)

Left-tailed Test

若 Ha:μ1−μ2<0H_a:\mu_1-\mu_2<0Ha​:μ1​−μ2​<0

Reject H0H_0H0​ if: zobs<−zαz_{obs}<-z_\alphazobs​<−zα​

p-value: p-value=P(Z<zobs)p\text{-value}=P(Z<z_{obs})p-value=P(Z<zobs​)

Two-tailed Test

若 Ha:μ1−μ2≠0H_a:\mu_1-\mu_2\neq0Ha​:μ1​−μ2​​=0

Reject H0H_0H0​ if: ∣zobs∣>zα/2|z_{obs}|>z_{\alpha/2}∣zobs​∣>zα/2​

p-value: p-value=2P(Z>∣zobs∣)p\text{-value}=2P(Z>|z_{obs}|)p-value=2P(Z>∣zobs​∣)

Confidence interval: (xˉ1−xˉ2)±zα/2σ12n1+σ22n2(\bar x_1-\bar x_2)\pm z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}(xˉ1​−xˉ2​)±zα/2​n1​σ12​​+n2​σ22​​​

若 CI 不包含 0，Reject H0H_0H0​。

Two-sample Pooled t Test: Equal Variances Unknown

Assumptions

X1i∼N(μ1,σ2)X_{1i}\sim N(\mu_1,\sigma^2)X1i​∼N(μ1​,σ2)

X2j∼N(μ2,σ2)X_{2j}\sim N(\mu_2,\sigma^2)X2j​∼N(μ2​,σ2)

且:

  • 兩組 samples independent。
  • σ12=σ22=σ2\sigma_1^2=\sigma_2^2=\sigma^2σ12​=σ22​=σ2。
  • 共同 variance σ2\sigma^2σ2 未知。

Pooled Variance

sp2=(n1−1)s12+(n2−1)s22n1+n2−2s_p^2=\frac{(n_1-1)s_1^2+(n_2-1)s_2^2}{n_1+n_2-2}sp2​=n1​+n2​−2(n1​−1)s12​+(n2​−1)s22​​

sp=sp2s_p=\sqrt{s_p^2}sp​=sp2​​

pooled variance 依照各組的 degrees of freedom (n-1) 加權

Pooled t Statistic

在 H0:μ1−μ2=0H_0:\mu_1-\mu_2=0H0​:μ1​−μ2​=0 下:

tobs=(xˉ1−xˉ2)−0sp1/n1+1/n2t_{obs}=\frac{(\bar x_1-\bar x_2)-0}{s_p\sqrt{1/n_1+1/n_2}}tobs​=sp​1/n1​+1/n2​​(xˉ1​−xˉ2​)−0​

且 T∼tn1+n2−2T\sim t_{n_1+n_2-2}T∼tn1​+n2​−2​

所以: df=n1+n2−2df=n_1+n_2-2df=n1​+n2​−2

目前的 pooled t test 只能用在 equal-variance assumption 下。

Robustness of t Procedures

One-sample t Procedure

  • Sample size n<15n<15n<15
    • 資料應接近 Normal；若有明顯 skewness 或 outliers，不建議使用 t procedure。
  • Sample size n≥15n\ge15n≥15
    • 除非有明顯 outliers 或 strong skewness，通常可使用 t procedure。
  • Large Sample
    • Sample 很大時，即使 population 明顯 skewed，t procedure 通常仍可使用。

Two-sample t Procedure

  • 通常比 one-sample t procedures 更 robust。
