樹與森林

名詞 定義/性質
Tree 連通 (connected) 且無環 (acyclic) 的圖。
Forest 每一個連通分支 (component) 都是樹；等價於無環圖。
Leaf 在至少有兩個頂點的普通樹中，度數為 111 的頂點。
Internal vertex 普通樹中不是葉節點的頂點 (根樹中的葉、內部點另依子節點數判斷)。
Cut-edge / Bridge (割邊) 移除後增加連通分支數的邊。樹的每一條邊都是割邊。
Cut-vertex (割點) 移除頂點及其關聯邊後，增加連通分支數的頂點。樹的葉節點不是割點。
  • 特例：K1K_1K1​、K2K_2K2​、PnP_nPn​、星圖 K1,nK_{1,n}K1,n​ 都是樹。
  • 森林若有 nnn 個頂點與 ccc 個連通分支，則 m=n−cm=n-cm=n−c (邊數)。

樹的基本性質

  • 樹的邊數: 若 TTT 有 nnn 個頂點，∣E(T)∣=n−1{|E(T)|=n-1}∣E(T)∣=n−1 (講義 P13)
  • 當 n≥2n\ge2n≥2 時，樹至少有兩個度數為 111 的頂點。 (講義 P16-17)
  • 對樹中任兩個不同頂點 u,vu,vu,v，恰好存在唯一一條 u−vu-vu−v 路徑。連通保證存在。 (講義 P19-20)
    • 若有兩條不同簡單路徑，會形成環，矛盾。
  • 對 n≥3n\ge3n≥3 的樹，割邊恰有 n−1n-1n−1 條；至少兩個葉子不是割點，因此割點至多 n−2n-2n−2 個。

對 nnn 個頂點的圖 TTT，以下敘述等價：

  • TTT 是樹（連通且無環）。
  • TTT 連通且 ∣E(T)∣=n−1|E(T)|=n-1∣E(T)∣=n−1。
  • TTT 無環且 ∣E(T)∣=n−1|E(T)|=n-1∣E(T)∣=n−1。
  • TTT 連通且每一條邊都是割邊。
  • 任意兩個不同頂點間有唯一一條路徑。
  • TTT 無環，且在任意兩個原本不相鄰的頂點間加上一條邊，會形成唯一一個環。

只有 m=n−1m=n-1m=n−1，不能判定是樹；還需確認連通或無環。
證明在講義 P28-31

  • 樹的中心恰為一個頂點，或一對相鄰的頂點。

    • 找樹中心的方式: 反覆同時移除所有葉節點，直到只剩一個頂點或相鄰兩點。此過程保留中心。

生成樹與計數

生成樹 Spanning tree：GGG 的一個子圖 TTT，同時滿足 V(T)=V(G)V(T)=V(G)V(T)=V(G) 且 TTT 為樹。連通圖至少有一棵生成樹；可以不斷刪去環上的邊得到。

  • 每棵生成樹都恰好有 n−1n-1n−1 條邊。
  • 若 GGG 有 mmm 條邊，則其生成子圖總數為 2m2^m2m。
  • 在固定 nnn 個有標號頂點上，簡單圖總數為: 2(n2)=2n(n−1)/2{2^{\binom n2}=2^{n(n-1)/2}}2(2n​)=2n(n−1)/2

Cayley 定理: 對 n≥2n\ge2n≥2，KnK_nKn​ 的生成樹數量 (頂點有標號，不以同構合併) 是 nn−2{n^{n-2}}nn−2

有根樹 Rooted tree

選樹 TTT 的一個頂點 rrr 作根，記為 (T,r)(T,r)(T,r)。不同的根會產生不同的有根樹結構。

名詞 定義
Root 指定為起點的頂點，沒有父節點。
Parent 對非根節點 uuu，根到 uuu 的唯一簡單路徑中緊鄰 uuu 的前一個頂點。
Child 某節點相鄰的頂點中，除父節點外，沿樹向下的頂點。
Sibling 具有相同父節點的兩個節點。
Ancestor 根到 uuu 的路徑上除 uuu 外的所有節點。
Descendant 若根到 uuu 的路徑包含 xxx，則 uuu 是 xxx 的子孫。
Leaf 在有根樹中，沒有任何子節點的節點。
Internal vertex 在有根樹中，至少有一個子節點的節點；根即使只有一個子節點，仍是內部點。
  • 普通無根樹常以 deg⁡(u)=1\deg(u)=1deg(u)=1 定義葉；有根樹則以子節點數 =0=0=0 判斷葉。
  • 根只有一條相鄰邊時，度數雖為 1，卻不是有根樹的葉節點。

二元樹 Binary tree

二元樹: 每個節點最多兩個子節點，且分左子節點／右子節點；左右位置有區別，不可任意互換。

左子樹／右子樹: 以某節點的左／右子節點為根向下形成的子樹。

  • 節點深度 Depth: 根到該節點的路徑長度；根深度為 000。
  • 節點高度 Height: 該節點往下走到子孫葉節點的最長路徑長度；葉節點高度為 000。
  • 整棵樹高度 hhh: 根節點的高度；深度 iii 那層最多有 2i2^i2i 個節點。

高度為 hhh 的一般二元樹，總頂點數 nnn 的界限: h+1≤n≤2h+1−1{h+1\le n\le 2^{h+1}-1}h+1≤n≤2h+1−1

反推樹高的下界: h≥⌈log⁡2(n+1)⌉−1{h\ge\lceil\log_2(n+1)\rceil-1}h≥⌈log2​(n+1)⌉−1

有 kkk 個內部點的二元樹，節點總數最多為 2k+12k+12k+1。

類型 判準 特別性質
Full binary tree 每個節點的子節點數恰好是 0 或 2。 若有 kkk 個內部點：總節點 2k+12k+12k+1，葉節點 k+1k+1k+1。
Complete binary tree 除最後一層外每層全滿，最後一層由左至右填入。 2h≤n≤2h+1−12^h\le n\le 2^{h+1}-12h≤n≤2h+1−1。
Perfect binary tree 每一層全部填滿。 n=2h+1−1n=2^{h+1}-1n=2h+1−1；同時是 Full 與 Complete。

Full binary tree: 2h+1≤n≤2h+1−1{2h+1\le n\le2^{h+1}-1}2h+1≤n≤2h+1−1
