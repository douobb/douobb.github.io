L5 Coloring of Graph

符號 意義
χ(G)\chi(G)χ(G) 著色數 (chromatic number)

ω(G)\omega(G)ω(G) 團數 (clique number)

Vertex Coloring 點著色

圖 GGG 的 kkk-著色是一個映射 f:V(G)→Sf:V(G)\to Sf:V(G)→S, 其中 ∣S∣=k|S|=k∣S∣=k。

若對任意 uv∈E(G)uv\in E(G)uv∈E(G) 都有 f(u)≠f(v)f(u)\ne f(v)f(u)​=f(v)，則稱為 proper kkk-coloring。

若 GGG 存在 proper kkk-coloring ，則稱 GGG 為 kkk-colorable。

所有同色頂點形成一個 color class ，且每個 color class 都是 independent set。

Chromatic Number 著色數

圖 GGG 的著色數記為 χ(G)\chi(G)χ(G)，表示完成 proper vertex coloring 所需的最少顏色數。

要證明 χ(G)=k\chi(G)=kχ(G)=k，通常要做兩件事:

  • 找到 proper kkk-coloring, 得到 χ(G)≤k\chi(G)\le kχ(G)≤k
  • 證明不存在 proper (k−1)(k-1)(k−1)-coloring, 得到 χ(G)≥k\chi(G)\ge kχ(G)≥k

常見圖:

  • χ(Kn)=n\chi(K_n)=nχ(Kn​)=n
  • χ(Pn)=2\chi(P_n)=2χ(Pn​)=2 for n≥2n\ge2n≥2
  • 非平凡樹 TTT: χ(T)=2\chi(T)=2χ(T)=2
  • χ(Km,n)=2\chi(K_{m,n})=2χ(Km,n​)=2
  • nnn 偶數時 χ(Cn)=2\chi(C_n)=2χ(Cn​)=2
  • nnn 奇數時 χ(Cn)=3\chi(C_n)=3χ(Cn​)=3

二部圖與著色

對簡單連通圖 GGG, 下列條件等價:

  • χ(G)=2\chi(G)=2χ(G)=2
  • GGG 是 bipartite graph
  • GGG 沒有 odd cycle

因此要證明一個圖不能 2-color，最常用的方法是找出 odd cycle。

Subgraph 與著色數

若 HHH 是 GGG 的子圖， 則 χ(H)≤χ(G)\chi(H)\le\chi(G)χ(H)≤χ(G)。
因此若 Kr⊆GK_r\subseteq GKr​⊆G, 則 χ(G)≥r\chi(G)\ge rχ(G)≥r。

Clique 與 Clique Number

Clique 是一組兩兩相鄰的頂點。

圖 GGG 中最大的 clique 的頂點數稱為 clique number, 記為 ω(G)\omega(G)ω(G)。

因為 clique 中每個頂點都必須使用不同顏色: χ(G)≥ω(G)\chi(G)\ge\omega(G)χ(G)≥ω(G)

Independent Set

令 α(G)\alpha(G)α(G) 為最大 independent set 的大小。

每個 color class 都是一個 independent set, 因此一種顏色最多只能包含 α(G)\alpha(G)α(G) 個頂點。

所以: χ(G)≥⌈n(G)α(G)⌉\chi(G)\ge \left\lceil\frac{n(G)}{\alpha(G)}\right\rceilχ(G)≥⌈α(G)n(G)​⌉

Join of Graphs

G∨HG\vee HG∨H 表示保留兩圖原有邊， 再將 GGG 的每個頂點和 HHH 的每個頂點全部相連。

因此兩圖不能共用顏色: χ(G∨H)=χ(G)+χ(H)\chi(G\vee H)=\chi(G)+\chi(H)χ(G∨H)=χ(G)+χ(H)

同時: ω(G∨H)=ω(G)+ω(H)\omega(G\vee H)=\omega(G)+\omega(H)ω(G∨H)=ω(G)+ω(H)

Coloring 方法

Greedy Coloring

Greedy Coloring 的做法:

  1. 先決定頂點順序
  2. 依序處理每個頂點
  3. 每次選擇尚未被已著色鄰居使用的最小顏色
  • Greedy 一定得到合法 coloring
  • 不保證是 minimum coloring
  • 頂點排序會影響最後使用的顏色數

Delta Plus One

對任意簡單圖 GGG: χ(G)≤Δ(G)+1\chi(G)\le\Delta(G)+1χ(G)≤Δ(G)+1

每個頂點最多只有 Δ(G)\Delta(G)Δ(G) 個鄰居， 因此即使這些鄰居全使用不同顏色， 準備 Δ(G)+1\Delta(G)+1Δ(G)+1 色仍一定有一色可用。

只有 KnK_nKn​ 與 CkC_kCk​ (奇環) 可能達到上界

Welsh-Powell Theorem

令頂點 degree 依非遞增順序排列: d1≥d2≥⋯≥dnd_1\ge d_2\ge\cdots\ge d_nd1​≥d2​≥⋯≥dn​

則: χ(G)≤1+max⁡imin⁡{di,i−1}\chi(G)\le 1+\max_i\min\{d_i,i-1\}χ(G)≤1+maxi​min{di​,i−1}

第 iii 個頂點前面只有 i−1i-1i−1 個頂點， 且自己最多有 did_idi​ 個鄰居， 所以前面最多有 min⁡{di,i−1}\min\{d_i,i-1\}min{di​,i−1} 個相鄰頂點。

Brooks’s Theorem

若 GGG 是簡單連通圖， 且 GGG 不是完全圖或奇環， 則: χ(G)≤Δ(G)\chi(G)\le\Delta(G)χ(G)≤Δ(G)

一般上界是 χ(G)≤Δ(G)+1\chi(G)\le\Delta(G)+1χ(G)≤Δ(G)+1, Brooks’s Theorem 將大部分 connected simple graph 改進成 Δ(G)\Delta(G)Δ(G)。

證明可分為四種情況 (講義 P39-50):

  • Δ(G)=2\Delta(G)=2Δ(G)=2
  • Δ(G)≥3\Delta(G)\ge3Δ(G)≥3, 且不是 regular
  • Δ(G)≥3\Delta(G)\ge3Δ(G)≥3, 是 regular 但不是 2-connected
  • Δ(G)≥3\Delta(G)\ge3Δ(G)≥3, 是 regular 且 2-connected

Mycielski Construction

Mycielski construction 可構造出 clique 很小但 chromatic number 很大的圖。

設 V(G)={v1,…,vn}V(G)=\{v_1,\dots,v_n\}V(G)={v1​,…,vn​}。

新增:

  • U={u1,…,un}U=\{u_1,\dots,u_n\}U={u1​,…,un​}: 若 viv_ivi​ 在原圖中與某頂點相鄰， 則 uiu_iui​ 也與該頂點相鄰
  • 一個新頂點 www 與所有 uiu_iui​ 相鄰

若 GGG 是 K3K_3K3​-free 且 χ(G)=k\chi(G)=kχ(G)=k, 則經 Mycielski construction 得到的圖 HHH:

  • 仍是 K3K_3K3​-free
  • χ(H)=k+1\chi(H)=k+1χ(H)=k+1

證明在講義 P57-64

因此可以建構出 ω(G)=2\omega(G)=2ω(G)=2, 但 χ(G)\chi(G)χ(G) 任意大的圖。
這表示: χ(G)=k\chi(G)=kχ(G)=k 並不代表 GGG 一定含有 KkK_kKk​ 子圖。
