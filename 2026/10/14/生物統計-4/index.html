Random Variable

Definition

Random variable 是將 sample space 中的 outcome 映射到 real line 的函數。

X:S→RX:S\rightarrow\mathbb{R}X:S→R

也就是把隨機實驗的結果轉成一個可以分析的數值。

Types of Random Variables

  • Discrete Random Variable: possible values 可以一一列舉
  • Continuous Random Variable: possible values 為連續數值

Discrete Random Variables

  • Probability Mass Function (PMF): p(x)=P(X=x)p(x)=P(X=x)p(x)=P(X=x)

    • ∑xP(X=x)=1\sum_x P(X=x)=1∑x​P(X=x)=1

  • Cumulative Distribution Function (CDF): F(x)=P(X≤x)F(x)=P(X\le x)F(x)=P(X≤x)

    • F(x)=∑a≤xP(X=a)F(x)=\sum_{a\le x}P(X=a)F(x)=∑a≤x​P(X=a)
    • F(x)F(x)F(x) 為 non-decreasing function
    • discrete CDF 是階梯狀函數

Bernoulli Random Variable

Bernoulli trial 只有兩種 outcome: Success/Failure

Y={1,success0,failureY=\begin{cases}1, & \text{success}\\0, & \text{failure}\end{cases} Y={1,0,​successfailure​

若 success probability 為 p: Y∼Bernoulli(p)Y\sim Bernoulli(p)Y∼Bernoulli(p)

且:

P(Y=1)=pP(Y=1)=pP(Y=1)=p

P(Y=0)=1−pP(Y=0)=1-pP(Y=0)=1−p

合併寫成:

P(Y=y)=py(1−p)1−y,y=0,1P(Y=y)=p^y(1-p)^{1-y},\quad y=0,1P(Y=y)=py(1−p)1−y,y=0,1

Binomial Random Variable

  1. 固定 trial 次數 n
  2. 每次只有 success / failure
  3. trials independent
  4. 每次 success probability 都相同為 p
  5. X = n 次 trials 中 success 的次數

若符合: X∼Binomial(n,p)X\sim Binomial(n,p)X∼Binomial(n,p)

則: P(X=x)=(nx)px(1−p)n−xP(X=x)=\binom{n}{x}p^x(1-p)^{n-x}P(X=x)=(xn​)px(1−p)n−x

  • E(X)=npE(X)=npE(X)=np
  • Var(X)=np(1−p)Var(X)=np(1-p)Var(X)=np(1−p)
  • Standard deviation: SD(X)=np(1−p)SD(X)=\sqrt{np(1-p)}SD(X)=np(1−p)​
