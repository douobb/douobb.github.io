Matchings and Covers

名詞 定義／判斷方式
Matching (匹配) 一組兩兩沒有共同端點的邊；一個頂點最多被選中的一條邊使用。
Perfect matching (完美匹配) 覆蓋所有頂點的匹配，即 V(M)=V(G)V(M)=V(G)V(M)=V(G)。因此頂點總數必為偶數。
MMM-saturated (被 MMM 飽和) 頂點屬於 V(M)V(M)V(M)，即與 MMM 中某條邊相接。
MMM-unsaturated (未被 MMM 飽和／自由頂點) 頂點不屬於 V(M)V(M)V(M)。
Maximal matching (極大匹配) 不能保留既有選邊再多加一條邊的匹配。
Maximum matching (最大匹配) 全圖之中邊數最多的匹配；大小為 α′(G)\alpha'(G)α′(G)。
  • maximum ⇒\Rightarrow⇒ maximal；maximal 不一定 maximum。
  • Perfect matching 若存在，必為 maximum，且 ∣M∣=n(G)/2|M|=n(G)/2∣M∣=n(G)/2。
  • #PerfectMatching⁡(K2n)=(2n)!2nn!\#\operatorname{PerfectMatching}(K_{2n})=\frac{(2n)!}{2^n n!}#PerfectMatching(K2n​)=2nn!(2n)!​
    • 排列 2n2n2n 個頂點，有 (2n)!(2n)!(2n)! 種
    • 每對內部交換不變: 除以 2n2^n2n
    • nnn 對交換次序不變: 除以 n!n!n!
  • MMM-alternating path (MMM-交錯路徑): 路徑上的邊依序交替「屬於 MMM／不屬於 MMM」。
  • MMM-augmenting path (MMM-增廣路徑): 起點、終點都是 MMM-unsaturated 的交錯路徑；首尾兩條邊必不在 MMM，路徑上「非 MMM 邊」比「MMM 邊」多一條。
  • 沿增廣路徑翻轉:保留路徑外的原匹配邊；路徑內把原本選中的邊移除，把原本未選的邊加入。

對稱差: A△B=(A−B)∪(B−A)=(A∪B)−(A∩B)A\triangle B=(A-B)\cup(B-A)=(A\cup B)-(A\cap B)A△B=(A−B)∪(B−A)=(A∪B)−(A∩B)

兩個匹配 M,M′M,M'M,M′ 的對稱差構成的非孤立連通分支，只可能是:

  • 邊在兩組匹配間交替的路徑，或
  • 邊數為偶數的交錯環。

原因:在 M△M′M\triangle M'M△M′ 中，每個頂點至多各接一條來自 MMM、M′M'M′ 的邊，故度數至多 2；若形成環，兩種邊交替，環長必偶數。

Berge 定理 : M 是 maximum matching  ⟺  G 不存在 M-augmenting pathM\text{ 是 maximum matching}\iff G\text{ 不存在 }M\text{-augmenting path}M 是 maximum matching⟺G 不存在 M-augmenting path

  • 若有增廣路徑，翻轉可讓邊數 +1+1+1。反之，若存在更大的匹配 M′M'M′，則 M△M′M\triangle M'M△M′ 中必有一個分支的 M′M'M′ 邊數比 MMM 邊數多；該分支即 MMM-增廣路徑。 (講義 P13,20)

Hall’s Matching Condition

Hall 婚姻定理:

對 (X,Y)(X,Y)(X,Y) 二部圖 GGG: $ \exists\text{ 匹配飽和 }X\iff\forall S\subseteq X,\quad |N(S)|\ge |S|$

  • XXX 中任意一組需求者 SSS，它們能連到的候選對象數量不能少於需求者數量。

  • 必要性: 若每個 x∈Sx\in Sx∈S 都匹配到不同的 YYY 頂點，則 N(S)N(S)N(S) 至少有 ∣S∣|S|∣S∣ 個頂點。

  • 充分性反向論證: 若最大匹配 MMM 未飽和 XXX，取未飽和頂點 u∈Xu\in Xu∈X；令 SSS 為從 uuu 經交錯路徑可達的 XXX 頂點，T=N(S)T=N(S)T=N(S) 為可達的 YYY 頂點。由 Berge 定理無增廣路徑，TTT 中每個頂點都被 MMM 配對到 S−{u}S-\{u\}S−{u}，故 ∣N(S)∣=∣T∣=∣S∣−1<∣S∣|N(S)|=|T|=|S|-1<|S|∣N(S)∣=∣T∣=∣S∣−1<∣S∣ ，與 Hall 條件矛盾。 (講義 P26–27)

任何 k≥1k\ge1k≥1 的 kkk-正則二部圖都有 perfect matching。

  • k∣X∣=∣E(G)∣=k∣Y∣  ⟹  ∣X∣=∣Y∣k|X|=|E(G)|=k|Y|\implies |X|=|Y|k∣X∣=∣E(G)∣=k∣Y∣⟹∣X∣=∣Y∣
  • 任意 S⊆XS\subseteq XS⊆X，由邊數計算: k∣S∣≤k∣N(S)∣  ⟹  ∣N(S)∣≥∣S∣k|S|\le k|N(S)|\implies |N(S)|\ge|S|k∣S∣≤k∣N(S)∣⟹∣N(S)∣≥∣S∣

因此由 Hall 定理有飽和 XXX 的匹配，且 ∣X∣=∣Y∣|X|=|Y|∣X∣=∣Y∣，故為 perfect matching。 (講義 P29)

Min–Max Theorems 與各種覆蓋

名詞 選 需要滿足 最佳化目標／記號
Matching (匹配) 邊 每個點至多被一條選邊使用 最大: α′(G)\alpha'(G)α′(G)
Vertex cover (頂點覆蓋) 頂點 每一條邊至少一個端點被選到 最小: β(G)\beta(G)β(G)
Independent set (獨立集) 頂點 任意兩個選中點不相鄰 最大: α(G)\alpha(G)α(G)
Edge cover (邊覆蓋) 邊 每一個頂點至少與一條選邊相接 最小: β′(G)\beta'(G)β′(G)

匹配和頂點覆蓋

對任意 matching MMM 與任意 vertex cover SSS:

∣M∣≤∣S∣  ⟹  α′(G)≤β(G){|M|\le |S|\quad\implies\quad \alpha'(G)\le\beta(G)}∣M∣≤∣S∣⟹α′(G)≤β(G)

  • 每條匹配邊必至少有一個端點被 SSS 選中，且不同匹配邊不能共用端點。 (講義 P35-36)

  • König–Egerváry 定理: G 是二部圖  ⟹  α′(G)=β(G)G\text{ 是二部圖}\implies \alpha'(G)=\beta(G)G 是二部圖⟹α′(G)=β(G)

頂點覆蓋與獨立集

S 為 vertex cover  ⟺  V(G)−S 為 independent setS\text{ 為 vertex cover}\iff V(G)-S\text{ 為 independent set}S 為 vertex cover⟺V(G)−S 為 independent set

α(G)+β(G)=n(G)\alpha(G)+\beta(G)=n(G)α(G)+β(G)=n(G)

  • 若補集中還有相鄰的兩個頂點，就有一條邊的兩端都未被原集合覆蓋。

邊覆蓋與匹配 (Gallai 定理)

若 GGG 沒有孤立點 (δ(G)≥1\delta(G)\ge1δ(G)≥1)，則 α′(G)+β′(G)=n(G)\alpha'(G)+\beta'(G)=n(G)α′(G)+β′(G)=n(G)

證明在講義 P46-49

二部圖且無孤立點的推論:

α′=β,α+β=n,α′+β′=n  ⟹  α(G)=β′(G)\alpha'=\beta,\quad \alpha+\beta=n,\quad \alpha'+\beta'=n \quad\implies\quad \alpha(G)=\beta'(G)α′=β,α+β=n,α′+β′=n⟹α(G)=β′(G)

Augmenting Path Algorithm (增廣路徑演算法)

  1. 給定二部圖 (X,Y)(X,Y)(X,Y) 和目前匹配 MMM；U=X−V(M)U=X-V(M)U=X−V(M) 為 XXX 側未飽和頂點。
  2. 初始化 S=US=US=U、T=∅T=\varnothingT=∅。自 UUU 開始擴展交錯路徑:從 XXX 沿非匹配邊到 YYY，若 YYY 頂點已匹配，再沿匹配邊回 XXX；將可達的 X,YX,YX,Y 頂點分別收進 S,TS,TS,T。
  3. 若抵達未匹配的 YYY 頂點，就得到增廣路徑 PPP:更新 M←M△E(P)M\leftarrow M\triangle E(P)M←M△E(P)，匹配數 +1+1+1，重新執行。
  4. 如果搜尋完仍找不到增廣路徑，按 Berge 得最大匹配，並按 König–Egerváry 得最小頂點覆蓋: M maximum,C=(X−S)∪T minimum vertex coverM\text{ maximum},\quad C=(X-S)\cup T\text{ minimum vertex cover}M maximum,C=(X−S)∪T minimum vertex cover

Matchings in General Graphs

Factor (因子)

名詞 定義
Factor (因子) 原圖的生成子圖: 保留全部頂點，邊可以減少。
kkk-factor (kkk-因子) 每個頂點在該生成子圖中的度皆為 kkk，即 kkk-正則生成子圖。
1-factor 一個 1-正則生成子圖，與 perfect matching 的邊可一一對應。
2-factor 一個 2-正則生成子圖；由涵蓋全部頂點的互不相交環構成。
  • perfect matching 是一組邊集合；1-factor 是由該匹配邊構成的生成子圖。

Odd component

  • Odd component: 頂點數為奇數的連通分支。
  • o(G)o(G)o(G): 奇數階分支的個數。

對任意 S⊆V(G)S\subseteq V(G)S⊆V(G)，有奇偶關係 o(G−S)+∣S∣≡n(G)(mod2)o(G-S)+|S|\equiv n(G)\pmod2o(G−S)+∣S∣≡n(G)(mod2)

  • G−SG-SG−S 的偶數階分支貢獻偶數個頂點；奇數階分支的頂點總數與 odd component 個數同奇偶。 (講義 P87)

Tutte 的 1-factor 定理

G 有 perfect matching (1-factor)  ⟺  ∀S⊆V(G),o(G−S)≤∣S∣G\text{ 有 perfect matching (1-factor)}\iff \forall S\subseteq V(G),\quad o(G-S)\le|S|G 有 perfect matching (1-factor)⟺∀S⊆V(G),o(G−S)≤∣S∣

  • 刪掉 SSS 後，每個奇數階分支如果要被原圖中的完美匹配完全覆蓋，都至少有一個頂點必須透過匹配邊連向 SSS；不同奇數分支需要不同的 SSS 頂點。
