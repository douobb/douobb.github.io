Vertex Cut 與 Connectivity

  • Vertex Cut (點割)

    • 對連通圖 GGG，若頂點集合 S⊆V(G)S\subseteq V(G)S⊆V(G) 滿足 G−SG-SG−S 有超過一個 connected component，則稱 SSS 為 vertex cut (點割)。

  • kkk-connected (kkk-連通)

    • 若從圖 GGG 中移除任意少於 kkk 個頂點後仍然連通，則稱 GGG 是 kkk-connected。
    • G 是 k-connected  ⟺  ∀S⊆V(G), ∣S∣<k, G−S 仍連通G \text{ 是 } k\text{-connected} \iff\forall S\subseteq V(G),\ |S|<k,\ G-S\text{ 仍連通}G 是 k-connected⟺∀S⊆V(G), ∣S∣<k, G−S 仍連通
    • kkk-connected ⇒(k−1)\Rightarrow (k-1)⇒(k−1)-connected。反之不一定成立。

  • Connectivity (連通度): κ(G)\kappa(G)κ(G)

    • 使 G−SG-SG−S 不連通或只剩一個頂點的頂點集合 SSS 的最小大小。
    • κ(G)=min⁡∣S∣\kappa(G)=\min |S|κ(G)=min∣S∣
    • 其中 SSS 使得 G−SG-SG−S 不連通，或 G−SG-SG−S 僅剩一個頂點。

如何證明 κ(G)=k\kappa(G)=kκ(G)=k？

  • κ(G)≥k\kappa(G)\ge kκ(G)≥k:移除任意少於 kkk 個頂點仍連通，也就是 GGG 是 kkk-connected。
  • κ(G)≤k\kappa(G)\le kκ(G)≤k:找到某一個大小為 kkk 的 vertex cut。

Edge Cut 與 Edge-connectivity

  • Edge Cut (邊割)
    • 對連通圖 GGG，若邊集合 S⊆E(G)S\subseteq E(G)S⊆E(G) 滿足 G−SG-SG−S 不連通，則稱 SSS 為 edge cut(邊割)。
  • kkk-edge-connected (kkk-邊連通)
    • 若從 GGG 中移除任意少於 kkk 條邊後仍然連通，則稱 GGG 是 kkk-edge-connected。
    • kkk-edge-connected ⇒(k−1)\Rightarrow(k-1)⇒(k−1)-edge-connected。反之不一定。
  • Edge-connectivity (邊連通度)
    • λ(G)=min⁡{∣S∣:S⊆E(G), G−S 不連通}\lambda(G)=\min\{|S|:S\subseteq E(G),\ G-S\text{ 不連通}\}λ(G)=min{∣S∣:S⊆E(G), G−S 不連通}

若 X,Y⊆V(G)X,Y\subseteq V(G)X,Y⊆V(G) 且 X∩Y=∅X\cap Y=\varnothingX∩Y=∅，則 [X,Y]={xy∈E(G):x∈X, y∈Y}[X,Y]=\{xy\in E(G):x\in X,\ y\in Y\}[X,Y]={xy∈E(G):x∈X, y∈Y} 表示 XXX 與 YYY 之間所有的邊。

最小邊割的性質

若 SSS 是 GGG 的最小 edge cut，則 G−S 恰有兩個 connected componentsG-S\text{ 恰有兩個 connected components}G−S 恰有兩個 connected components

若切成三個以上 components，通常可以只保留其中一部分割邊就把圖切開，得到更小的 edge cut，與「最小」矛盾。 (講義 P29–30)

對簡單圖 GGG: κ(G)≤λ(G)≤δ(G)\kappa(G)\le\lambda(G)\le\delta(G)κ(G)≤λ(G)≤δ(G)

Blocks

Block(塊): 沒有 cut vertex 的極大連通子圖 (maximal connected subgraph with no cut vertex)。

Block 不一定是 2-connected，因為 K1K_1K1​、K2K_2K2​ 也可能是 block。

若 B1,B2B_1,B_2B1​,B2​ 是不同 blocks，則 ∣V(B1)∩V(B2)∣≤1|V(B_1)\cap V(B_2)|\le1∣V(B1​)∩V(B2​)∣≤1，兩個不同 blocks 最多共用一個頂點。

  • 若共用兩個不同頂點，可以證明 B1∪B2B_1\cup B_2B1​∪B2​ 仍沒有 cut vertex，與 block 的 maximal 性質矛盾。 (講義 P41)

尋找 blocks，使用 DFS:

  1. 建立 DFS tree。
  2. 追蹤目前 subtree 是否有 back edge 連到父節點以上的 ancestor。
  3. 若某 subtree 無法透過 back edge 回到 parent 以上，則該 subtree 與 parent 形成一個 block。
  4. 記錄後將該部分從目前 DFS tree 中移除。

頂點/邊不相交路徑與 kkk-connected

  • Vertex-disjoint Paths (頂點不相交路徑)
    • 兩條 u−vu-vu−v path 若除了起點 uuu、終點 vvv 外沒有任何共同頂點，稱為頂點不相交。

2-connected 的等價條件:

對至少 3 個頂點的圖 GGG，下列條件等價:

  • GGG 連通且沒有 cut vertex。
  • 任意兩頂點 x,yx,yx,y 間有兩條 vertex-disjoint x−yx-yx−y paths。
  • 任意兩頂點 x,yx,yx,y 都在同一個 cycle 上。
  • δ(G)≥1\delta(G)\ge1δ(G)≥1，且任意一對 edges 都包含在某一個 cycle 中。

證明在講義 P60–63

擴張引理:

若 GGG 是 kkk-connected，加入新頂點 yyy，並讓 yyy 與 GGG 中任意 kkk 個頂點相鄰，則所得新圖仍為 kkk-connected。

G 是 k-connected, d(y)≥k⟹G+y 仍為 k-connectedG\text{ 是 }k\text{-connected},\ d(y)\ge k\Longrightarrow G+y\text{ 仍為 }k\text{-connected}G 是 k-connected, d(y)≥k⟹G+y 仍為 k-connected

證明依 被刪除的集合 SSS 是否包含 yyy 分兩種 case。 (講義 P58–59)

連接兩個 kkk-connected graphs

若 G,HG,HG,H 是頂點不相交的 kkk-connected graphs:

  • 要保證將 G,HG,HG,H 接起來後仍是 kkk-connected，至少需要在兩圖之間加入 kkk 條 matching edges。
  • 若 ∣V(G)∣=∣V(H)∣|V(G)|=|V(H)|∣V(G)∣=∣V(H)∣ 且兩圖之間加入一組 perfect matching，講義指出所得圖為 (k+1)(k+1)(k+1)-connected。 (講義 P64–69)
  • Edge-disjoint Paths (邊不相交路徑)
    • 兩條 u−vu-vu−v paths 沒有共同 edge，就稱為邊不相交。
    • vertex-disjoint⇒edge-disjoint\text{vertex-disjoint}\Rightarrow\text{edge-disjoint}vertex-disjoint⇒edge-disjoint，反之不一定成立。

對任意 e∈E(G)e\in E(G)e∈E(G): κ(G)−1≤κ(G−e)≤κ(G)\kappa(G)-1\le\kappa(G-e)\le\kappa(G)κ(G)−1≤κ(G−e)≤κ(G)
也就是刪除一條 edge，頂點連通度最多下降 1。 (講義: 72–74)

Menger’s Theorem

  • x,yx,yx,y-separator
    • 給定 x,y∈V(G)x,y\in V(G)x,y∈V(G)，若 S⊆V(G)−{x,y}S\subseteq V(G)-\{x,y\}S⊆V(G)−{x,y}，且 G−SG-SG−S 中不存在 x−yx-yx−y path，則稱 SSS 為 x,yx,yx,y-cut / x,yx,yx,y-separator。
  • κ(x,y)\kappa(x,y)κ(x,y): x,yx,yx,y-separator 的最小大小。
  • λ(x,y)\lambda(x,y)λ(x,y): x,yx,yx,y 之間最大數量的兩兩 vertex-disjoint paths。

Menger Theorem (Vertex Version):

若 x,yx,yx,y 是圖 GGG 中兩個不相鄰頂點，則 κ(x,y)=λ(x,y)\kappa(x,y)=\lambda(x,y)κ(x,y)=λ(x,y)

分開 x,yx,yx,y 所需要移除的最少頂點數 = x,yx,yx,y 之間最大數量的兩兩頂點不相交路徑。

應用:

G 是 k-connected  ⟺  G 的任意兩頂點間都有 k 條兩兩 vertex-disjoint pathsG\text{ 是 }k\text{-connected}\iff G\text{ 的任意兩頂點間都有 }k\text{ 條兩兩 vertex-disjoint paths}G 是 k-connected⟺G 的任意兩頂點間都有 k 條兩兩 vertex-disjoint paths

因此，若 GGG 為連通圖，任意兩頂點至少存在 κ(G)\kappa(G)κ(G) 條兩兩 vertex-disjoint paths。

Menger Theorem (Edge Version):

對任意頂點 x,yx,yx,y: 分開 x,y 所需移除的最少 edge 數=最大兩兩 edge-disjoint x−y paths 數\text{分開 }x,y\text{ 所需移除的最少 edge 數}=\text{最大兩兩 edge-disjoint }x-y\text{ paths 數}分開 x,y 所需移除的最少 edge 數=最大兩兩 edge-disjoint x−y paths 數

應用:

G 是 k-edge-connected  ⟺  任意兩頂點間有 k 條兩兩 edge-disjoint pathsG\text{ 是 }k\text{-edge-connected}\iff\text{任意兩頂點間有 }k\text{ 條兩兩 edge-disjoint paths}G 是 k-edge-connected⟺任意兩頂點間有 k 條兩兩 edge-disjoint paths

若 GGG 是 kkk-connected，則 ∣V(G)∣≥k(diam⁡(G)−1)+2|V(G)|\ge k(\operatorname{diam}(G)-1)+2∣V(G)∣≥k(diam(G)−1)+2

取距離等於 diameter 的 x,yx,yx,y，Menger 保證至少有 kkk 條兩兩 vertex-disjoint x−yx-yx−y paths；每條 path 除 x,yx,yx,y 外至少有 diam⁡(G)−1\operatorname{diam}(G)-1diam(G)−1 個頂點。

Max-Flow Min-Cut Theorem

若 flow fff 的 value 在所有合法 flows 中最大，則 fff 是 maximum flow。

  • f(N)=max⁡f∗f∗(N)f(N)=\max_{f^*}f^*(N)f(N)=maxf∗​f∗(N)
  • 最大 flow 的配置方式可能不唯一，但 maximum flow 的值是唯一的。

在所有 cuts 中，從 source side 到 sink side 的總 capacity 最小者稱為 minimum cut。

  • min⁡(P,P‾)c(P,P‾)\min_{(P,\overline P)}c(P,\overline P)min(P,P)​c(P,P)
  • minimum cut 也可能不唯一。

Residual Network 與 Augmenting Path

剩餘網路用來記錄每個 arc 還可以增加多少 flow。

講義版本的 residual capacity: cf(x,y)=c(x,y)−f(x,y)c_f(x,y)=c(x,y)-f(x,y)cf​(x,y)=c(x,y)−f(x,y)
也就是 剩餘容量=原容量−目前流量\text{剩餘容量}=\text{原容量}-\text{目前流量}剩餘容量=原容量−目前流量

在 residual network 中，若存在一條從 sss 到 ttt 的 path，則稱為 augmenting path。

  • 該 path 表示還可以增加 flow。
  • 一次可以增加的量由路徑上最小 residual capacity 決定: Δf=min⁡e∈Pcf(e)\Delta f=\min_{e\in P}c_f(e)Δf=mine∈P​cf​(e)

Ford-Fulkerson 與 Edmonds-Karp

Ford-Fulkerson Algorithm 核心流程:

  1. 初始化 f=0f=0f=0。
  2. 建立 residual network。
  3. 在 residual network 找一條 s−ts-ts−t augmenting path PPP。
  4. 找 PPP 上最小 residual capacity。
  5. 依該 bottleneck 增加 flow，更新 residual network。
  6. 重複直到找不到 augmenting path。

Edmonds-Karp 是 Ford-Fulkerson 的具體版本: 每次用 BFS 找 residual network 中 edge 數最少的 augmenting path。
